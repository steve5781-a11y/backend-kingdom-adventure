# 🏰 백엔드 왕국 대모험

만화로 배우고, 단어를 외우고, 퀴즈 게임으로 공주를 구하는 **백엔드 필수 개념 학습 사이트**

## 기능
- 📖 **만화 학습** — 10개 챕터 (클라이언트·서버, HTTP, REST, DB/SQL, 인덱스·트랜잭션, 인증·인가, 캐시, 확장, 메시지 큐, 배포)
- 🃏 **단어 카드** — 뒤집는 플래시카드, 외움 체크
- ⚔️ **퀴즈 모험** — 정답이면 전진, 오답이면 하트 감소, 10칸 끝 보스를 물리치고 공주 구출
- 📝 **오답 노트** — 틀린 문제 자동 저장, 오답 리벤지 모드

## 실행
빌드 없이 `index.html`을 브라우저로 열면 됩니다. 학습 기록은 브라우저(localStorage)에 저장돼요.

## 내용 수정
만화 대사·설명·단어·퀴즈는 모두 `js/data.js`에 있어요.
